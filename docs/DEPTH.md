# 深度登记 临床试验访视窗与方案锁库核验

规模：中型。使用者：临床试验数据管理员。核心规则：按入组基准计算访视半开窗，方案修订按受试者生效时间选版；漏访不可用复检伪填。

## 对账规则

原始逻辑输入=采纳行+隔离行+空行+重复表头+同值重复。业务计算按 DATA-DICTIONARY.md 分别核验，不能把上级与下级重复加总。所有隔离保留编号、原值、原始行号和稳定原因码。药物交接另按回传行=采信事件+重试行+隔离行对账，重试不计盒；访谈视结算里“访视未完成”与偏离模块同源，锁库阻断总量只计一次。

## 已知不覆盖

数据来自仓内样例或用户粘贴文件，不连接外部业务生产系统。平台不执行实际资金划转或行政审批。
